Optional SQLite driver (enables the SQL database instead of the fallback file storage).
Download sqlite-jdbc-3.36.0.3.jar (self-contained, no other libraries needed) from:
https://repo1.maven.org/maven2/org/xerial/sqlite-jdbc/3.36.0.3/sqlite-jdbc-3.36.0.3.jar
and place it in this folder. Then run ./run.sh web (or run.bat web).
